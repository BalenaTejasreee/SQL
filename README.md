## 🧠 My Practice Approach

I am not only trying to memorize SQL queries.

For every problem, I am working on understanding:

**What is the question asking? → Which SQL concept is needed? → How should I build the query? → Why does the query work?**

I also keep track of my mistakes and corrections because I believe that understanding mistakes is an important part of improving.
